# Technology readiness – HMI-Timing

| Level | Status | Evidence |
|-------|--------|----------|
| TRL 1–2 | done | concept: time-to-certified-diagnosis and a NO_MATCH state for an unrecognised accident |
| TRL 3 | done | `src/hmitime/` loader, window features, split-conformal sets, display policy, Mahalanobis and energy scores |
| TRL 4 | **reached for closed-set timing only (simulator)** | public NPPAD runs, `outputs/results.json` regenerated by `scripts/run_experiment.py`, filing card `docs/REGISTRATION.md`, unit tests, CI in `.github/workflows/ci.yml` |
| TRL 5 | not reached | needs plant or full-scope-simulator replay with known initiating events, and an operator study |

The open-set safeguard is **not** at TRL 4. Holding out one accident type, the empty conformal set, the Mahalanobis distance, and the logistic energy score all fail to flag that type reliably. Details are in the README and `outputs/results.json`.

Known limits: one simulated PWR, 12 accident types with CSV runs, no sensor faults, no operator actions after insertion, no safety classification.
